# All Weather Drill workshop artwork

The current approved workshop banner is **AllWeatherDrill-WorkshopPreview-960x540.png**, sized **960 × 540 pixels** to match the sample. The companion JPEG is a compact copy of the same image.

The **Refreshing** weather panel depicts refreshing rain, **not snow**. This corrects the earlier visual concept.

For a Steam Workshop update, select the PNG as the item's preview image. Timberborn does not use this banner as a separate in-game mod icon.

These assets are not game DLLs and do not change mod behavior. The actual mod files are under `AllWeatherDrill/version-...`.
